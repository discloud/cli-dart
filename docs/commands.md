```sh
A fast option to manage your apps on Discloud.

Usage: discloud <command> [arguments]

Global options:
-h, --help       Print this usage information.
    --debug      Use this to diagnose errors or bugs.
    --version    Print version. (v0.0.0)

Available commands:
  app         Manage your apps
  domain      Manage your domains
  init        Init discloud.config file
  login       Login on Discloud API
  snapshot    Manage your versioned backups
  subdomain   Manage your subdomains
  team        Manage team apps
  user        Manage your profile
  zip         Make zip

Run "discloud help <command>" for more information about a command.
```
