### [zip](zip.md)

```sh
Make zip

Usage: discloud zip [arguments]
-h, --help           Print this usage information.
-g, --glob=<**>      
-o, --out            Zip output
-l, --level=<0-9>    Compression level
-p, --password       Zip password

Run "discloud help" to see global options.
```
